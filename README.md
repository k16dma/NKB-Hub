## 🇬🇧 English: ScenarioDesigner (SD)
**ScenarioDesigner** is a powerful, intuitive Robotic Process Automation (RPA) platform built for Windows. It is designed to help power users and businesses automate repetitive tasks with absolute precision.

### ✨ Key Features
- **Intelligent Coordinate Scaling:** Cross-DPI adaptation ensures your automation scripts run flawlessly across different monitor resolutions.
- **Smart Actions:** Includes advanced image searching (`FindImage`, `SmartClick`), optical character recognition (`FindText`, `ExtractText`), and complex control flows (`If`, `While`, `Repeat`).
- **Condition Expression Parser:** Supports complex logical evaluations with parentheses grouping, e.g., `(a = 1 or b = 2) and c = 3`.
- **High Security:** Employs AES-256 encryption for scenario files, Nonce-based Secure Binding, and Dual Burned Guard to prevent unauthorized copying.
- **Global Undo System:** Built-in `.trash` mechanism for scenario recovery.

### ✨ Tính năng nổi bật
- **Nội suy độ phân giải (Cross-DPI Adapt):** Kịch bản tạo trên màn hình FullHD vẫn chạy chuẩn xác trên màn hình HD nhờ thuật toán nội suy tự động.
- **Công cụ nhận diện thông minh:** Hỗ trợ tìm hình ảnh (`SmartClick`), quét chữ OCR (`FindText`), và các vòng lặp logic nâng cao (`If`, `While`).
- **Xử lý biểu thức toán học:** Hỗ trợ tính toán logic ngoặc đơn phức tạp `(a = 1 or b = 2) and c = 3`.
- **Bảo mật tuyệt đối (AES-256):** Kịch bản được mã hóa gắn chặt với phần cứng máy tính (Hardware ID) và hệ thống cấp phép Dual Burned Guard.
- **Hoàn tác an toàn:** Tích hợp thùng rác thông minh giúp bạn không bao giờ lo mất dữ liệu khi lỡ tay xóa kịch bản.
